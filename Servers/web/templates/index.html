What's New in PlusOS 3.1 — The Universal Loader Release
🚀 NEW IN 3.1 • ONE IMAGE, EVERY 680x0 MAC

Build Once. Boot Anywhere.

PlusOS 3.1 introduces the Universal Loader: a single PlusOS.hda that boots a Macintosh Plus, SE, Classic (68000) or an LC III (68030), detecting the CPU and hardware at run time — exactly the way System 7 ships one System file for every Macintosh. Move the same card between machines and it just boots.

🌐 Universal Loader

One image for the Plus, SE, Classic, and LC III. The kernel reads CPUFlag ($012F) at boot and adapts console geometry, framebuffer, keyboard, ROM trap tables, 68030 cache coherency, and A-line dispatch automatically. Build it with MACHINE=universal.

🧩 Modular Self-Healing Kernel

Every subsystem is a supervised module — drivers and services that talk over named pipelines. A built-in supervisor isolates and restarts any module that fails, so a crashing driver no longer takes the machine down with it.

🐞 In-Kernel Crash Debugger

Faults are caught, shown on an on-screen debugger panel, and written to a post-mortem PlusOS CrashDump — then recovered from instead of resetting the Mac. Decode dumps offline with plusdump and its built-in 68000 disassembler.

🖥️ Full LC III (68030) Support

Native 640×480 Sonora video, NCR 53C96 high-speed SCSI, 68030 instruction/data cache management, and a direct Toolbox dispatch path for user-mode apps — all gated at run time so the same binary still runs on an 8 MHz 68000.

Developer Tools — PlusOS Disk Studio & Multi-Threaded Compiler
⚡ NEW IN PLUSOS 3.1

PlusOS Disk Studio (PlusOSDiskStudio.exe)

A high-performance, native Win32/C++ companion tool located directly in the root of the repository. PlusOS Disk Studio provides a complete graphical operating system builder, non-blocking multi-threaded compiler with real-time log streaming, dual-boot system configurator, and full dual-pane Macintosh HFS hard drive manager.

⚡ Non-Blocking Async Compiler

Compilations (make install & make floppy) execute in dedicated background worker threads. Windows never freezes or shows "(Not Responding)", while compiler stdout/stderr streams line-by-line into the live log window in real time.

📦 66-App Checklist & Boot Core Sizing

Granular checkbox control over all 66 packages. Automatically includes the mandatory Base OS Core (~191 KB Kernel, Boot Blocks, and HFS overhead) required to boot before calculating total footprint, ensuring disks truly fit on hardware.

💾 Floppy Capacity Rules (800K vs 1.44M)

Real-time capacity tracking against vintage floppy hardware limits. Automatically guides you to keep software under ~609 KB (Total < 800 KB) for standard 800K Macintosh Plus/SE disks, or up to 1.44 MB for High Density SuperDrives, with safety prompts.

🔍 Automatic Compile Directory Scanner

Both Disk Studio and install.py automatically scan build/apps/*.pex. Any newly compiled 68000 binary is detected instantly, added to the package checklist with its exact size, and marked for installation.

🔄 Classic Mac OS "Return to PlusOS" Injector

Dual-booting between System 7 and PlusOS? Inject the native Classic Mac OS executable (APPL/PLOS) into any image or external disk. Launching it inside Mac OS rewrites XPRAM offset $78 and issues _Restart ($A888) to seamlessly return to PlusOS.

🗂️ Dual-Pane Drag & Drop HFS Explorer

Browse folder hierarchies and files with Mac FourCC Type/Creator inspection. Drag files from Windows Explorer directly into vintage HFS disk images with automatic metadata tagging, export files, or delete items.

🌐 Universal Portability & BlueSCSI Auto-Scan

Runs portably in any folder without hardcoded drive assumptions. If the PlusOS repository is missing, it offers to download and set it up automatically from GitHub. Automatically scans drives D: through Z: to detect BlueSCSI SD cards.

🐧 Native Linux Edition & TUI (make studio)

Linux developers can compile and run Disk Studio natively without Windows (./PlusOSDiskStudio or make studio). Includes an interactive terminal TUI and CLI commands to inspect partitions, list HFS trees, extract/import files, and compile images.

🔒 Mandatory Shell Lock & Env Setup

The core PlusOS Command Shell (SHELL) is permanently locked as required to boot across all package selection presets. Includes a one-click Setup Environment button to install requirements.txt and verify WSL Ubuntu.

💽 Minimal Bootable Installer Floppy (PlusOS_Floppy.dsk)

A zero-bloat ~500 KB bootable floppy disk image containing only the essential bootloader, kernel, shell, desktop, and the guided hard drive installer (installer.pex) with strictly zero games. Boot on physical hardware or Mini vMac to partition, format, and provision any SCSI hard drive.

⚡ Quick 3-Step Setup for BlueSCSI V2:
  1. Copy PlusOS.hda onto the root of your MicroSD card and name it HD60_512 PlusOS.hda (SCSI ID 6).
  2. (Optional for Wi-Fi) In bluescsi.ini, enter your WiFiSSID and WiFiPassword, and create an empty file named NE4.hda.
  3. Insert the card into your BlueSCSI, power on your Macintosh Plus or SE, and enjoy PlusOS 3.1!
